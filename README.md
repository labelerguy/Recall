# Recall

Sir's learning headquarters: any topic, for class or not, studied with methods backed by primary research. No account, no paywall.

**Open it:** https://labelerguy.github.io/Recall/

## Modes
- **Learn**: spaced repetition. Cards you miss come back in the same session and sooner next time.
- **Cram**: every card, ignoring the schedule. For the last 48 hours before an exam.
- **Blank-page test**: predict your score, answer every card from memory, then see predicted vs. actual.
- **Flip cards**: recognition only. The weakest mode.

## Topics and decks
The dashboard shows **topics** (Art History Exam 3, Countries, anything). Each topic holds one or more **decks** and can have an exam or goal date.

Easiest way to add one: tell Claude "I want to learn ___" and it writes the deck and topic (see `CLAUDE.md`).

By hand: add a deck file to `decks/` and list it under a topic in `topics.json`.

You can also paste a Quizlet export into **Import a set**. That deck lives only in that browser until its file is added to the repo.

## Progress
Saved in your browser. Each device keeps its own. Use **Export progress** to back it up.
